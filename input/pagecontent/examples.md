### Repeat Progression Sequence Example

This guide includes a multi-dispense MedicationDispense sequence that demonstrates repeat progression across six dispense events for the same prescription. Use these representative examples to verify implementation logic that determines whether further repeats remain:

1. Dispenses 1 to 5 (represented by [MedicationDispense Repeat Progression Example 1 of 6](MedicationDispense-medicationdispense-repeat-progression-example-1.html)) use the repeat status code `repeat-active`.
2. Dispense 6 (final), shown in [MedicationDispense Repeat Progression Example 6 of 6 (Final)](MedicationDispense-medicationdispense-repeat-progression-example-6.html), uses the repeat status code `repeat-completed`.
