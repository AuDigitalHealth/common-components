### Repeat Progression Sequence Example

This guide includes a multi-dispense MedicationDispense sequence that demonstrates repeat progression across six dispense events for the same prescription.

1. Dispenses 1 to 5 use the repeat status code `repeat-active`.
2. Dispense 6 (final) uses the repeat status code `repeat-completed`.

Use these examples to verify implementation logic that determines whether further repeats remain:
